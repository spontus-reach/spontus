# Support

Need help with Spontus? Use the channel that best matches the request so maintainers can route it quickly.

## Bug Reports

Use the **Bug or workflow problem** issue template when something is broken or behaving unexpectedly.

Open a bug report: <https://github.com/spontus-reach/spontus/issues/new?template=bug-workflow-problem.yml>

Use this template for:

- Product or prototype defects
- Broken repository automation
- Failing agent or skill workflows
- Incorrect or misleading documentation

## Feature Requests

Use the **Feature idea** issue template to propose product improvements for teams, sponsors, admins, or repository workflows.

Open a feature request: <https://github.com/spontus-reach/spontus/issues/new?template=feature-idea.yml>

Use this template for:

- New product capabilities
- Improvements to existing features
- Solutions to user pain points or business risks

## General Questions

GitHub Discussions is not enabled for this repository. For general questions about strategy, research synthesis, or operating context, use the contact link configured in the issue template chooser.

- [Spontus HQ in Notion](https://www.notion.so/a13ae01f89cf82adafb101ea94d6d1ab?pvs=1) - Use the Notion HQ for strategy, research synthesis, and operating context.
