## Documentation Standards

- Use standard Markdown links so docs work in GitHub, editors, and documentation tools.
- Keep filenames lowercase and dash-separated.
- Add status metadata to major pages: `Canonical`, `Reference`, `Draft`, or `Superseded`.
- Keep imported source notes intact when possible; add summaries and indexes around them.
- Record durable product, GTM, engineering, and operations decisions in [Decision Log](./decision-log.md).
- Use GitHub issues and PRs for execution tracking.
