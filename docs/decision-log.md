## How To Add A Decision

1. Create a new file in `strategy/` or `engineering/` using `_templates/decision-record.md`.
2. Use a filename like `YYYY-MM-DD-short-decision.md`.
3. Fill in context, decision, and consequences.
4. Add a link to the new record in this index.
